Real Estate Data Clustering Analysis
📌 Project Overview
This repository focuses on unsupervised machine learning (clustering analysis) applied to real estate market data. By grouping similar properties based on numerical attributes (such as price, square footage, bedrooms, and location metrics), this project helps uncover hidden patterns in real estate listings and categorize properties into meaningful market segments.

📂 Repository Structure
├── real estate.csv      # Dataset containing raw real estate features and property records
├── clustering_plot.py   # Python script performing data processing, model training, and visualization
└── cluster plot.png     # Visual output plot illustrating property clusters and decision boundaries

⚙️ Key Workflow & Methodologies
Data Preprocessing & Standardisation:

Loads raw property data from real estate.csv.

Preprocesses numerical features and applies standard scaling to balance feature weightings.

Clustering Algorithm Execution:

Implements clustering models (e.g., K-Means or Hierarchical Clustering) using scikit-learn.

Segments data points into optimal clusters to highlight distinct property tiers (e.g., budget, mid-range, luxury).

Data Visualization:

Generates a clear scatter plot displaying clusters and centroids.

Exports high-resolution visual analysis directly to cluster plot.png.

🚀 Getting Started
1. Prerequisites
Ensure you have Python 3.8+ installed along with the required libraries:

pip install pandas numpy matplotlib seaborn scikit-learn

2. Installation & Setup
Clone this repository to your local machine:

git clone https://github.com/RakshanaQ/real-estate.git
cd real-estate

3. Running the Analysis
Run the primary script to perform clustering and generate the visual output:

python clustering_plot.py

Upon execution, the script processes the dataset and automatically updates or saves cluster plot.png in the root folder.
